# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React, Tailwind CSS v4, pnpm workspaces, Cloudflare Workers and Think/Agents. TanStack Router owns navigation; TanStack Query owns ordinary server reads.

## Users

The single operator returns to one personal assistant to assign, inspect and redirect several kinds of work.

## Product Purpose

Stead is a proof of concept for a persistent personal assistant. Its main conversation remains available while retained tasks work independently. People can return to saved conversation, tasks, files, personal notes and an explicitly scheduled responsibility.

## Capabilities and Constraints

The proof of concept supports cited research, small uploaded dataset analysis, bounded artifact creation, durable task corrections, explicit stop and resume, inspectable text/Markdown/CSV/code files, editable personal notes and a scheduled responsibility. Connection health is separate from task outcome. Interrupted work never silently resumes when the browser opens. Model completion alone does not establish a completed task.
